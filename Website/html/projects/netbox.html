NetBox — Infrastructure Source of Truth

Install and configure NetBox as the source of truth for device inventory and IP address management, feeding future Terraform/Ansible automation and the Prometheus/Grafana monitoring stack.

Host: netbox01, Debian 13.6 Stack: Python 3.13.5 · PostgreSQL 17 · Redis 8.0.2 Status: In Progress

Overview

A separate Debian VM (hostname netbox01) runs NetBox 4.6.8 as the planned infrastructure source of truth — device inventory (DCIM), IP address management (IPAM), and eventually virtualization tracking. The goal is for NetBox to feed both the Terraform/Ansible provisioning pipeline and device discovery for the Prometheus monitoring stack, rather than maintaining device lists by hand in multiple places.

Status

The install is fully working end to end: database migrations completed, a superuser created, static files collected, and web login tested successfully against Django's development server.

Next stage

Move off the Django dev server onto a production deployment — Gunicorn behind Nginx, managed as a systemd service — then begin populating DCIM/IPAM data and wiring NetBox into device discovery for Grafana and Prometheus, deliberately kept out of the initial Lab 07/09 monitoring setup so that piece could be built and proven independently first.
