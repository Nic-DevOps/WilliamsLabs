Redundant Switching, STP & EtherChannel Lab

Upgrade the office network with redundant switching infrastructure to eliminate single points of failure and provide multiple paths between devices.

Devices: 3 core, 3 access switches Protocols: Rapid PVST+, LACP Status: Complete

Overview

A redundant mesh topology replaces the single-path design from Lab 01. Three Layer 3-capable Catalyst 3650 core switches and three Catalyst 2960 access switches are cross-connected, with Spanning Tree Protocol preventing Layer 2 loops and LACP EtherChannel bundling redundant physical links into single logical connections.

Spanning Tree Protocol

Rapid PVST+ selects the lowest-cost path to the root bridge and blocks redundant links to prevent loops. Core1 is configured as the primary root bridge:

spanning-tree vlan 1 root primary

EtherChannel (LACP)

Physical links between core switches are bundled into logical port channels so STP treats them as one connection — keeping every member link active instead of blocking the redundant ones.

Failover testing

EtherChannel link failure: disabling one physical member interface left the Port Channel operational with no STP recalculation — traffic simply shifted to the remaining link.

STP path failure: disconnecting an active Layer 2 link triggered STP to transition a previously blocked path to forwarding, restoring connectivity automatically.
