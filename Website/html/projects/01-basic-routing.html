Basic Routing Lab

Build the initial network infrastructure for a small office and establish basic connectivity between four separate network segments.

Devices: 1 router, 4 switches, 16 PCs Focus: Static connectivity, subnetting Status: Complete

Overview

The starting point for the whole lab environment: four separate LANs, each on its own subnet, connected through a single Cisco ISR 4331 router acting as the default gateway for every segment. Each LAN uses a star topology — end devices connect to a Layer 2 Catalyst 2960 switch, and each switch uplinks to the router.

No routing protocol is needed here — all four networks are directly connected, so the router automatically populates its table with connected routes as each interface comes up.

Design trade-offs

Advantages: each LAN is its own broadcast domain, and the design is simple to configure and troubleshoot.

Limitations: the router is a single point of failure for inter-LAN traffic, and each switch is a single point of failure for its own LAN — the problem the next lab exists to solve.
