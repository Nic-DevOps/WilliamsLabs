Inter-VLAN Routing Lab

Introduce Layer 3 routing between the VLANs created in the previous lab using a router-on-a-stick design.

Design: Router-on-a-stick Router: Cisco ISR 4331 Status: Complete

Overview

A single router interface, trunked to the core switching layer over 802.1Q, provides gateways for all four VLANs via subinterfaces — one per VLAN. This keeps routing centralized and simple, at the cost of scalability: every inter-VLAN packet passes through one physical link.

Router-on-a-stick configuration

interface g0/0
 no shutdown

interface g0/0.10
 encapsulation dot1q 10
 ip address 10.0.10.1 255.255.255.0

interface g0/0.20
 encapsulation dot1q 20
 ip address 10.0.20.1 255.255.255.0
! (repeated for VLANs 30 and 40)

Verification

Three connectivity tests confirmed the design worked end to end: same-VLAN PC-to-PC, PC-to-gateway, and full inter-VLAN routing (HR PC to Engineering PC).

Trade-offs

Simple to configure and troubleshoot, but the router becomes a single point of failure for all inter-VLAN traffic, and there's no Layer 3 redundancy — the problem HSRP solves next.
