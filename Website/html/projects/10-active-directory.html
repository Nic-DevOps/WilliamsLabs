Active Directory Lab

Stand up a Windows Server 2022 domain controller with AD DS and DNS on the HQ server VLAN, join a client from a separate routed VLAN, and push user Group Policy to it end to end.

Domain: corp.williamslabs.ca DC: AD-01, 10.10.20.50 Status: Complete

Overview

Building on the multi-site network from Labs 06–09, this lab gives the CML topology a real Windows identity layer. AD-01 runs on VMware Workstation, bridged into the HQ server VLAN, and becomes the forest root domain controller and DNS server for corp.williamslabs.ca. A Windows client on the HQ user VLAN joins the domain across inter-VLAN routing and receives a user GPO, proving DNS, Kerberos and Group Policy all work between routed subnets.

The client and the DC sit on different subnets on purpose. Traffic between 10.10.10.0/24 and 10.10.20.0/24 is routed by SVIs on the HQ core switches (HSRP from Lab 05/06), the same path any real workstation would take to reach a domain controller.

Promoting the domain controller

The AD DS role is installed from Server Manager, then the server is promoted to a new forest with integrated DNS. The PowerShell equivalent:

Install-ADDSForest `
  -DomainName "corp.williamslabs.ca" `
  -DomainNetbiosName "CORP" `
  -ForestMode "WinThreshold" `
  -DomainMode "WinThreshold" `
  -InstallDns:$true `
  -SafeModeAdministratorPassword (ConvertTo-SecureString "<DSRM password>" -AsPlainText -Force)

Hostnames stay short (AD-01, AD-02, ...) and site context lives in NetBox rather than in the domain name or hostname, so the domain stays stable as DCs are added per site.

Group Policy

A Corp Users - Baseline GPO is linked to the Corp Users OU and enables Prohibit access to Control Panel and PC settings, a common baseline control that stops standard users changing system settings on managed workstations.

What's next

Planned: a firewall in front of the server VLAN allowing only the ports AD needs (DNS, Kerberos, LDAP, SMB, RPC), a fuller GPO baseline, LDAP signing and channel binding, and a domain controller per site mapped with AD Sites and Services.
