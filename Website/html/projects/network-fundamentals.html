Network Fundamentals Lab

Build a three-tier campus network end to end — switching, IPv4/IPv6 addressing, OSPF routing, network services, security, and management — on a single topology with an edge router to an ISP.

Platform: Cisco Modeling Labs (IOSv / IOSvL2) Design: Access / distribution / core + edge Status: Complete

Overview

A standalone campus lab, separate from the multi-site Williams Labs build. Two access switches connect hosts and IP phones, two Layer 3 distribution switches provide the VLAN gateways, two core switches route between distribution and the edge, and R1 connects the campus to an ISP router that hosts a server at 1.1.1.1.

LAN switching

  • VLANs 10 CLIENTS, 20 VOICE, 30 PRINTERS, 40 MANAGEMENT, with a data + voice VLAN access port for IP phones
  • Access switches negotiate trunks with DTP (dynamic desirable); distribution switches trunk statically
  • LACP EtherChannel between DSW1 (active) and DSW2 (passive); a static Layer 3 EtherChannel between the core switches
  • Rapid PVST+ with DSW1 as root for every VLAN and DSW2 as secondary
  • PortFast and BPDU Guard by default on edge ports, with errdisable auto-recovery after 10 minutes
  • Custom STP timers (3 s hello, 10 s forward delay, 20 s max age) set on every switch so they survive a root change

30 PRINTERS10.0.0.192/281410.0.0.193
40 MANAGEMENT10.0.0.208/29610.0.0.209

Subnets are sized largest-first as tightly as the device counts allow. Loopbacks use /32s from 10.0.255.0/24, internal point-to-point links use /30s from 10.0.250.0/24, and R1 reaches the ISP on 172.16.1.0/30.

IPv6 addressing

From 2001:db8::/32, the fourth hextet mirrors the IPv4 plan: 2001:db8:0:<vlan>::/64 for VLANs, 2001:db8:0:255::x/128 for loopbacks, and a /127 on the R1–ISP link. Internal point-to-point links run on link-local addresses only.

Routing

! R1 — default routes toward the ISP
ip route 0.0.0.0 0.0.0.0 172.16.1.2
ipv6 route ::/0 2001:db8:0:250::1

! Core bundle — no DR/BDR election, fast timers
interface Port-channel1
 ip ospf network point-to-point
 ip ospf hello-interval 5
 ip ospf dead-interval 15
  • OSPFv2 and OSPFv3 in a single area 0, with IPv4 loopbacks as router IDs
  • User VLANs passive on the distribution switches to avoid unneeded adjacencies
  • R1 originates the IPv6 default route into OSPFv3

Network services

ServiceImplementation
HSRPVLAN 10 virtual gateway 10.0.0.3 — DSW1 active (priority 110, preempt), DSW2 standby
DHCPPools on R1 for VLAN 10 (DNS 1.1.1.1, MYDOMAIN.LOCAL, 48-hour lease) and VLAN 20 (TFTP option 150), relayed by the distribution SVIs
NATPAT overload of 10.0.0.0/8 to R1's ISP-facing address
NTPHierarchy following the topology: 1.1.1.1 → R1 → core → distribution → access

Security & management

  • Login banner on R1 and a MOTD on CSW1
  • Port security on H1's port — one sticky MAC, shutdown on violation
  • Extended ACL on the VLAN 10 SVIs blocking HTTP to 1.1.1.1 while allowing everything else
  • SSH v2 only on CSW1 with a local user and encrypted passwords
  • Syslog from DSW1, CDP tuned to 5 s / 60 s and disabled toward hosts and the ISP, and LLDP on the access layer (off on uplinks, receive-only toward hosts)

Verification

  • show spanning-tree brief — DSW1 priority 0, DSW2 priority 28672 for every VLAN

  • H1 and H2 received 10.0.0.4 and 10.0.0.5 from R1 through the DHCP relay
  • show ip nat translations — H1 translated to 172.16.1.1 toward 1.1.1.1
  • SSH from H1 to CSW1's loopback shows the MOTD and lands in privileged mode
