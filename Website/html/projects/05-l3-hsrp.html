Layer 3 Switching & HSRP Lab

Upgrade the inter-VLAN routing infrastructure into a resilient Layer 3 network capable of maintaining gateway availability during device or path failures.

Redundancy: HSRP active/standby Core: 2× Cisco 3560 L3 Status: Complete

Overview

Routing moves off the single router and onto two Layer 3 core switches, each holding a Switch Virtual Interface (SVI) per VLAN. HSRP layers a shared virtual gateway IP on top of both SVIs so end devices keep a single, stable default gateway even if one core switch fails.

Key configuration

The core-to-core EtherChannel is converted from a switched trunk into a routed Layer 3 link:

interface range g1/0/5-6
 no switchport
 channel-group 10 mode active

interface port-channel 10
 no switchport
 ip address 10.0.0.1 255.255.255.252

HSRP is configured per SVI, with CORE-SW1 as active (higher priority) and CORE-SW2 as standby:

interface vlan 10
 standby 10 ip 10.0.10.1
 standby 10 priority 110
 standby 10 preempt

Failover test

With both core switches showing correct active/standby HSRP roles (show standby brief), the active core's SVI was shut down. The standby core immediately assumed the virtual gateway role, and connectivity to all VLANs remained available throughout.
